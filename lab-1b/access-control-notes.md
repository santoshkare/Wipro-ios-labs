
# Access Control in Swift

## 1. Private
Private restricts access to the enclosing declaration.
In this project, balance is private and cannot be accessed directly outside BankAccount.

## 2. Fileprivate
Fileprivate allows access within the same Swift file.
In this project, filePrivateValue demonstrates fileprivate access.

## 3. Internal
Internal allows access throughout the same module.
It is the default access level in Swift.

## 4. Public
Public allows access to a class or member from other modules.
In this project, AccessDemo and publicValue use public access.

## Conclusion
Access control protects data and provides controlled access to class members.
Encapsulation prevents unauthorized direct modification of account balance.
